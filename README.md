/# FFT
FFT analyser for waveforms
This MATLAB GUI calculates the frequency spectrum of well-known waveforms and data experimentally acquired. Select a test wave or load experimental data, choose a window (Hanning, Hamming, Flat top, Rectangular, Blackman) and a filter for experimental data, then click "Calculate FFT" to plot the spectrum.
